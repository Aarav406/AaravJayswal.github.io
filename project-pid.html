PID Temperature Controller & Custom Power Supply (Buck Converter)

PSpice Timer C PID Control

Project Details

  • Engineered a closed-loop thermal management system using an Arduino to continuously read environmental data from a DHT11 temperature and humidity sensor.
  • Implemented a Proportional-Integral-Derivative (PID) control algorithm in C to calculate precise output adjustments based on real-time thermal feedback.
  • Driven a DC cooling fan via pulse-width modulation (PWM), allowing the microcontroller to dynamically scale fan speed to maintain a strict temperature setpoint.
  • Designed and simulated a custom 10V-40V to 5V step-down buck converter using PSpice to ensure highly stable power delivery to the system.
  • Utilized an LM2576 voltage regulator paired with an optimized LC filter to minimize output voltage ripple, specifically providing clean, isolated 5V power to the sensitive DHT11 sensor and logic circuitry.

Hardware Integration & PID Tuning

A significant challenge in this build was fine-tuning the Proportional, Integral, and Derivative gains to prevent the cooling fan from over-correcting or oscillating around the target temperature. By integrating the custom buck converter, the sensitive DHT11 sensor was protected from voltage spikes and power noise, ensuring highly accurate PID calculations. Future scope includes upgrading the system with a telemetry dashboard (such as Foxglove Studio) to monitor temperature curves and PID response times in real-time.
