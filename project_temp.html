Temperature Monitoring System

Arduino UNO C++ Programming PWM Logic Analog Inputs

Project Details

  • Prototyped a temperature monitoring and alert system utilizing an Arduino UNO to process analog inputs and provide real-time visual feedback.
  • Simulated analog temperature signals using a 10KΩ potentiometer acting as a variable voltage divider connected to the microcontroller.
  • Programmed inverted PWM logic mapping to control a Common Anode RGB LED, effectively visually transitioning the LED from blue (cold) to red (hot) as the simulated temperature rises.
  • Designed an alarm system with conditional logic that triggers a flashing high-temperature warning LED when ADC readings reach a predefined threshold of 1000.
  • Streamlined the hardware layout and protected digital pins by placing a single 2kΩ current-limiting resistor on the common VCC line, restricting total current to roughly 2.5mA.

Hardware Integration & Future Scope

This build highlighted the critical differences between Common Anode and Common Cathode components, which requires fundamentally different software logic for sinking versus sourcing current[cite: 2]. Future improvements include swapping the potentiometer for a physical environmental sensor, such as a DHT11, and expanding the logic to drive a PWM-controlled fan for active thermal management.
